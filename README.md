# 学习工作台（0.9.0 开发版）

本机运行的学习与项目成长桌面应用。正式学习记录从空白开始，不读取本工作区的能力档案、教材或旧聊天。

## 从阅读到动手

- 首页直接浏览菜鸟教程原网站，保留网站目录、排版与跳转。右侧 AI 教学由你主动开启；它只收到当前标题、地址和你主动选取的段落，不复制整个网站。原站阅读需要网络。
- 左侧「动手学习」提供三个原创 JavaScript 单元：函数、列表处理、请求路径。先看讲解和最小例子，确认学过后再出现任务。写代码 → 本机运行 → 看具体失败 → 修改 → 自己解释 → 保存此次产出。
- 例如先学函数，再写 `greeting(name)`。漏写 `return` 时，反馈会指出实际返回值；改好后重跑。提示按需展开，记录里保留代码、输入、预期/实际结果、提示程度和解释。
- 基础任务通过后，从下一天开始可做变化任务。同一天过题不算长期掌握；系统只显示已有证据，不保证换一个问题也能独立解决。外部 AI 帮助需自己如实标记。
- 动手学习无需 API Key、Docker 或网络。代码在独立 QuickJS Worker 中执行：无网络、磁盘或宿主接口，限制时间、内存与输出；一次运行后销毁。

## 先用 3 分钟认识工作台

- 第一次打开，会显示四页简短介绍：学习流程、界面、常用工具、开始使用。可随时跳过；看过后不会每次启动都弹出。
- 从左侧「使用指南」／左下角用户菜单进入「快速体验」。无需 API Key、无需联网。
- 跟着内置的 **HTTP 请求** 示例选择知识点，模拟一次请求，再选中文字打开辅助对话。右侧标签可切换、关闭、恢复，结论由你手动带回示例草稿。
- 写一句回答，复述学到了什么，补充理解，完成体验打卡。讲解和补缺是固定示例，不会评价你的回答。
- 体验结束可直接进入模型设置或从首页选择自己的课程。体验输入在退出后清空；不会生成正式栏目、能力证据或真实打卡，也不会停止当天的学习提醒。

## 使用

1. 打开 `/Applications/学习工作台.app`（构建文件也保留在 `release/mac-arm64/学习工作台.app`）。在「设置 → 模型与接口」选择 OpenAI、DeepSeek 或自定义模板，填写自己的 API Key 和模型 ID，保存配置。
2. 首页浏览原站分类 → 课程 → 具体知识点。阅读不需要 API Key。需要讲解时打开右侧 AI，也可选中原文问一个问题。新建项目栏目可讨论实际目标、时间和执行阶梯。
3. 在学习聊天逐块听讲。学完后再点「这块学完了」接受一个问题；随后用自己的话复述学会了什么、还缺什么。AI 提议证据等级，自己确认。未补的缺口会挡住下一块；跳过标成待验证。仅有文字回答最多建议「初步理解」，实际代码与延迟变式记录在「动手学习」查看。
4. 在主聊天选中文字，右键选「辅助对话」。侧聊可隐藏、恢复，结论只会放进主聊天的未发送草稿。
5. 在「项目工作区」选择项目，检查文件、体积和疑似密钥，选复制范围。命令和 AI Agent 在 Docker 副本中运行；默认断网。Monaco 编辑器保存到副本；检查差异后可逐项应用到原项目。原文件变动时应用会被拒绝。
6. 在「设置」设提醒开始日期与时间、导出或恢复备份。备份不包含配置的 API Key。

关窗后软件留在菜单栏；菜单栏可重新打开或彻底退出。开机启动默认开启，可在设置中关闭。

## 语音输入与朗读

- 聊天输入框下方点「语音输入」，说完点「结束录音」。首次使用需允许麦克风权限。每次最多 60 秒；普通话、粤语和英语自动识别，文字进入草稿后自行发送。
- 使用内置 SenseVoice Small INT8 模型在本机处理，不需要语音 API Key，不上传录音。取消、切换栏目或隐藏窗口会停止录音。
- AI 回复旁点「朗读」，再点可停止。设置的「语音输入与朗读」中可选声音、语速，或开启自动朗读新回复；默认不自动播放。
- 录音只是输入方式，只有用户检查并发送后的回答才参与学习过程；朗读或录音动作本身不算能力证据。
- 引擎与模型的来源、许可随源码和安装包保留；不同平台的麦克风权限仍需在实际设备上检查。

## 开发与打包

需要 Node.js ≥22.13、pnpm 11.19.0。桌面构建目标为 Mac arm64/x64 和 Windows x64；当前真实 GUI 验收在 Mac arm64。项目运行功能需要 Docker Desktop；首次运行需能获取 `node:22-alpine` 镜像。从源码首次构建需下载并校验固定版本的语音引擎与模型。

```bash
pnpm install
pnpm test
pnpm typecheck
pnpm prepare:speech
pnpm test:voice-local
pnpm dev
pnpm package:mac
# Intel Mac 构建
pnpm package:mac:x64
# Windows x64 开发目录（建议在 Windows 上构建）
pnpm package:win
```

本机 Mac arm64 产物：`release/mac-arm64/学习工作台.app`。CI 为三个桌面目标检查代码、运行官方语音样例并创建未签名开发目录；不替代真实设备上的安装、麦克风、通知与登录项验收。Windows 系统朗读尚未实现。手机完整适配仍在开发，当前不可当作可安装的手机学习应用。

当前包为本机 ad-hoc 签名，未公证，不适合公开分发。系统通知和开机启动在不同 macOS 权限状态下可能需要分别检查；设置页可查看开机启动状态与最近提醒状态。

项目原创源码采用 MIT；第三方许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) 和 `licenses/`。第三方网站正文属于原站，不作为本项目源码发布。

## 数据与边界

- 栏目、聊天、侧聊、证据、打卡存于 Electron `userData/state.json`；API Key 仅在本次进程内存中使用，退出后需重新输入。此前尝试使用 macOS Keychain，但当前 ad-hoc 签名包在弹出访问授权时会卡住，因此首版暂不跨次启动保存 Key。
- 项目副本位于系统临时目录。退出时删除。疑似密钥文件和常见依赖目录默认不复制；如用户明确选中复制密钥，副本中的内容可能在项目 Agent 调用模型时被发送给所选提供方。
- Docker 命令使用隔离副本、默认断网、资源限制。网页预览需另开容器联网。
- 当前项目容器镜像是 `node:22-alpine`，主要适合 Node.js 项目；其他语言的依赖环境尚需扩展。

## 标签工作区与设置

- 顶部工作区按钮显示/隐藏右侧面板。「＋」可同时打开多个文件、辅助对话、终端、变更审查和网页预览。标签可拖动排序，右键可关闭其他或右侧标签。
- 每个标签有独立关闭按钮。⌘W 关闭当前右侧标签，⌘⇧T 恢复最近关闭。文件未保存时可保存、放弃或取消；关闭侧聊不会删除内容。切换栏目时，各栏目的标签和草稿互相独立。
- 标签、未发送草稿与未保存编辑只在本次运行内保留；退出前请保存代码。项目副本仍按原规则在退出时清理。
- 左下角用户菜单：入门介绍、快速体验、个人资料、设置、快捷键与退出。个人资料是本机学习偏好，不是在线账户。
- ⌘, 打开设置：常规、个人资料、外观、模型、教学、编辑器、语音、提醒、数据和快捷键。支持搜索设置。
- 可选择深色/浅色/跟随系统、界面字号、代码字号、自动换行、行号、小地图、缩进，以及 Enter 或 ⌘/Ctrl+Enter 发送。用户输入法正在选字时不会误发送。
- 昵称、长期目标、每日时间和教学偏好保存在本机；学习目标及教学偏好会随学习请求交给你配置的模型。备份包含这些设置，仍不含 API Key。
- 网页预览页只使用当前项目的 localhost 地址；页面被隔离在无应用接口的 iframe 中。禁止嵌入的网页可点「独立窗口」查看。

## 多 API 与多模型

- 「设置 → 模型与接口」上方显示已配置 API；下方用模板新增或手工填写配置。每组包含名称、地址、协议和多个模型 ID。模型可一行一个，也可用逗号分隔。
- 同一个 API Key 可以供该配置中的多个模型使用；不同 API 的 Key 分开保存。编辑配置时 Key 留空会保留本次 Key，改地址或协议则需要重新填写。
- 点击配置卡片上的模型，或在主聊天/辅助对话输入框旁选择「API 名称 / 模型」，下一次请求使用该选择。切换保留原对话和学习进度；回复旁显示产生它的接口及模型。
- 「测试连接」发送一个短请求验证所选模型，不会写入学习记录。模板只是预填值，实际可用模型由你的接口和 Key 权限决定。
- 元数据和选择状态会持久保存，旧版单接口自动转为一条「原有配置」。当前本机版本仍只在运行期间保留 Key，退出后会显示「待填写 Key」。备份不含 Key，恢复备份后也需重新填写。
- 配置名称、模型列表的普通编辑不会换用其他 API；移除当前模型会选择同一 API 的首个剩余模型。删除 API 时会选择另一已有配置，且保留学习记录。
- 模板只是预填协议和地址；模型与价格以接口提供方实际支持为准。

## 0.6.0 缓存与模型用量

打开「设置 → 模型与接口」查看各 API/模型的实际 token 和缓存读取比例。未报告字段显示「未提供」；累计比例只统计字段完整的请求，不估算金额。

编辑 API 后可为每个模型填写服务商标明的上下文窗口（token）；留空也能使用。窗口和输入用量均已知时接近 80% 自动整理，否则长聊天只提示手动整理。摘要能展开查看，原聊天和能力证据仍保留。手动整理会调用当前模型一次并计入用量。

升级重启后 API Key 需要重新填写。缓存比例是服务商实际返回的结果，不承诺一定命中或某个价格。


## 0.7.0 课程首页与轻量教材

- 内置菜鸟教程目录快照：12 个分类、149 门课程，JSON 36,833 字节。维护者可用 `node scripts/update-catalog.mjs` 显式刷新；运行时不遍历全站。
- 点课程才读目录，点知识点才读正文。本文与网页结构不兼容、断网或超时会显示错误，无法读取时不生成假教案。
- 章节按真实标题分小节；每次模型请求只附当前小节，原教程 URL 和版本一起校验。章末普通追问使用最后一小节复习材料。旧聊天、侧聊和证据保留。
- 原文标签可关闭、隐藏与恢复；原文内切换阅读小节不改变 AI 学习进度。图片主动点击后加载，媒体通过原站查看。
- 教程磁盘缓存上限 50 MiB。最久未使用的未固定材料优先清理，固定章也计入上限。固定用于离线阅读；在线模型教学仍需要可用接口。
- 设置 → 数据与备份显示缓存用量，可清理未固定或全部教材。学习答案、代码、侧聊、证据、打卡及版本绑定独立保存在 state.json。备份不包含教材缓存、API Key。
- 教程版本变化会阻止旧栏目混用新教材；从首页重新打开会建立新版本栏目，原记录保留。
- 这是早期课程提取模式的设计记录。当前首页优先使用原网站阅读；149 门课程并未逐页验收。
