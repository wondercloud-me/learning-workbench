原创离线实践

从函数、列表处理、路径与响应三个 JavaScript 单元起步。编辑代码，本机运行，对照每条预期与实际结果。

无需 API Key，无需 Docker。

按需获得帮助

先自己尝试，再逐步查看提示。选择自己的模型与接口，围绕当前材料提问，把结论带回自己的理解。

你的接口，你决定何时使用。

一次推进一步

先学，再用产出验证。

看过讲解只是起点。自己的代码、运行结果和解释，才是继续前进的依据。

  1. 01

    读懂一个小问题

    看概念、最小代码和预期现象，知道它在实际工程中的位置。确认学过，再进入任务。

  2. 02

    写出来，跑一下

    自己编辑代码，查看具体反馈。卡住时逐层看提示；每次尝试保留代码、结果和帮助程度。

  3. 03

    说清楚，再回来看

    用自己的话解释做法。次日起尝试变化任务，看能否把理解用在新的输入和条件上。

通过用例说明完成了这次任务。多次独立完成和自己的解释，能提供更多学习证据；软件不会承诺“保证学会”。

从这里开始

先体验，再配置自己的模型。

不必先购买模型服务，就能了解学习流程。

试试动手学习

在桌面应用中打开「动手学习」，选择一个单元。先看最小例子，确认学过，再编辑并运行你的代码。

内置原创实践可以离线使用；读取原站文章和在线 AI 需要网络。

需要 AI 时再连接

进入「设置 → 模型与接口」，填写自己的 API Key、接口与模型。测试连接会向所选接口发送一个短请求。

模型服务由你自行选择，使用费用与数据处理规则以对应服务商为准。
